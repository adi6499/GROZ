How to read the labels
Verified
A person has checked this product against its catalogue page.
Not yet verified
Shown in the product details: read from the catalogue automatically, not yet checked by a person.
Needs review
The extraction itself flagged a problem with this record.
Under review
A corrected reading of this value is awaiting approval, so the value is not shown.
Not specified
The catalogue table does not print this value for the product.
Family image
The catalogue image shows the product family, shared by related variants.
Image not confirmed
A picture is printed nearby, but nothing links it to this product, so it is not shown.
Printed title
The product title printed above the product's table in the catalogue; the product details say which page.
